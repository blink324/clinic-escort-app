# つきそい 倫理委員会準備チェックリスト

最終更新: 2026-08-27

## 0. 前提

- [ ] 本アプリは、通院予定の共有と付き添い調整を支援するアプリである
- [ ] 診断、治療方針、服薬、検査適応などの医療判断は行わない
- [ ] 医療機関と正式連携していると誤解される表現を使わない
- [ ] 「特定の予約票形式に対応した、利用者個人向けの予定登録支援機能」と説明する
- [ ] OCR結果は自動確定せず、必ず本人または家族の確認・修正を挟む

## 1. 研究・実証の目的

- [ ] 研究/実証の主目的を明文化する
- [ ] 対象者を明文化する
- [ ] 利用場面を明文化する
- [ ] 主要評価項目を決める
- [ ] 副次評価項目を決める
- [ ] 研究期間または実証期間を決める
- [ ] 参加者数の目安を決める
- [ ] 除外基準を決める

記載案:

> 高齢家族の通院予定を家族間で共有し、付き添い担当の決定と受診前リマインドを支援することで、通院予定の把握漏れや付き添い忘れを減らせるかを確認する。

## 5. OCR β機能

- [ ] 機能名を「予約票読み取りβ」とする
- [ ] 対象帳票を大学病院の特定予約票形式に限定する
- [ ] OCR前に注意文を表示する
- [ ] OCR処理は端末内で行う方針を明記する
- [ ] 元画像は原則保存しない
- [ ] OCR対象項目を限定する
- [ ] OCR対象外項目を明記する
- [ ] OCR結果確認画面を必須にする
- [ ] 確認画面で全項目を修正可能にする
- [ ] 「確認して登録」ボタンを押すまで予定に登録しない
- [ ] OCR失敗時は手入力へ自然に移れるようにする
- [ ] OCR精度検証用のサンプル予約票を匿名化して用意する

OCR対象項目:

- [ ] 病院名
- [ ] 診療科
- [ ] 予約日
- [ ] 予約時刻
- [ ] 検査名
- [ ] 受付場所

OCR前注意文案:

> 予約票の画像を端末内で読み取り、予定登録の候補を作成します。読み取り結果は自動登録されません。内容を確認・修正してから登録してください。患者番号や氏名など、予定登録に不要な情報は保存しません。

## 12. 主なリスクと対策

| リスク | 対策 |
| --- | --- |
| OCR誤認識で誤った予定が登録される | 自動登録せず確認画面を必須にする |
| 予約票画像に患者番号などが含まれる | 元画像は原則保存しない。不要項目は保存しない |
| 家族以外に共有URLが渡る | 長いランダムトークンを使う。共有内容を最小限にする |
| LINE通知が届かない | アプリ内でも予定確認できる。通知テスト機能を用意する |
| 付き添い担当が誤って登録される | 担当変更・削除を可能にする |
| 退会後にデータが残る | 関連データ削除のテストを行う |
| 医療機関公式サービスと誤解される | 表現を「個人向け予定登録支援」に統一する |
