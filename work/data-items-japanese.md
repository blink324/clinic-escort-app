# つきそい データ項目一覧 日本語版

最終更新: 2026-08-27

この資料は、Supabase上で保存しているテーブル/カラムを、倫理委員会や説明資料で使いやすい日本語のデータ項目に言い換えたものです。Supabase上の英語名を変更する必要はありません。

## 1. アカウント情報

Supabase Authで管理します。

| Supabase上の項目 | 日本語の項目名 | 用途 | 主な閲覧/利用範囲 | 削除 |
| --- | --- | --- | --- | --- |
| `auth.users.id` | ユーザーID | アプリ内で利用者を識別するため | システム | 退会時に削除 |
| `auth.users.email` | メールアドレス | ログイン、本人確認、確認メール送信のため | 本人、認証システム | 退会時に削除 |
| user metadata | 表示名 | アプリ内で本人の名前を表示するため | 本人、同じ共有先のメンバー | 退会時に削除 |

補足:

- パスワードはSupabase Authで管理され、アプリ側では平文保存しません。
- 表示名は本名である必要はなく、家族内で識別できる名前を想定します。

## 11. 現時点で保存しない/扱わない情報

| 保存しない/扱わない情報 | 理由 |
| --- | --- |
| 患者番号 | 通院予定共有と付き添い調整に必須ではないため |
| 診察券番号 | 通院予定共有と付き添い調整に必須ではないため |
| 保険者番号 | 本アプリの目的外であり、不要な保険情報のため |
| 生年月日 | 本アプリの目的外のため |
| 住所 | 本アプリの目的外のため |
| 病名/診断名 | 医療判断に関わる可能性があり、本アプリの目的外のため |
| 検査結果 | 本アプリの目的外のため |
| 処方内容 | 本アプリの目的外のため |
| 診療録/電子カルテ情報 | 医療機関システムと連携しないため |
| 医師の診断内容 | 本アプリの目的外のため |

## 12. OCR β機能追加時の予定データ項目

OCR β機能では、以下の候補を端末内OCRで読み取り、確認画面で利用者が修正・確定したものだけを予定登録に使用します。

| OCRで読み取る候補 | 保存方針 | 用途 |
| --- | --- | --- |
| 病院名 | 確認後に保存 | 通院予定登録 |
| 診療科 | 確認後に保存 | 通院予定登録 |
| 予約日 | 確認後に保存 | 通院予定登録 |
| 予約時刻 | 確認後に保存 | 通院予定登録 |
| 検査名 | 確認後に保存するか検討 | 持ち物/メモ補助 |
| 受付場所 | 確認後に保存するか検討 | メモ補助 |

OCRで読み取らない/保存しない方針:

- 患者番号
- 診察券番号
- 保険者番号
- 氏名
- 生年月日
- 病名/診断名
- 検査結果
- 処方内容

## 13. 倫理委員会向け説明文案

> 本アプリでは、通院予定の共有と付き添い調整に必要な範囲に限定して、患者表示名、病院名、診療科、受診日時、持ち物、メモ、付き添い担当者名、リマインド設定、LINE通知設定等を保存する。患者番号、診察券番号、保険者番号、病名、検査結果、処方内容、電子カルテ情報等は本アプリの目的外であり、保存対象としない。
>
> 予約票写真は、利用者が任意で添付した場合に保存される。ただし、OCR機能追加後は、予約票画像は原則として端末内で読み取り、元画像は保存しない設計とする。OCR結果は自動登録せず、利用者が確認・修正した後にのみ通院予定として登録する。
